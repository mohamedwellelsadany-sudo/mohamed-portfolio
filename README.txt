To preview:
Open index.html in a browser.

To publish with GitHub Pages:
1. Create a new PUBLIC repository on GitHub.
2. Upload the contents of this folder (not just the ZIP file). Make sure index.html is in the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Choose branch main and folder /(root), then Save.
6. Wait a minute or two; GitHub will show the published website URL in the Pages section.

The design uses Google Fonts when internet is available; the site itself remains usable without them.
